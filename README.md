# 🎮 John's Game - Unity 2D Platformer

Proyecto de videojuego de plataformas en 2D desarrollado en **Unity 6**, integrado con **Firebase Firestore** para la persistencia de datos y guardado de puntuaciones en la nube, y adaptado con controles responsivos para una experiencia de juego fluida.

---

## 🌟 Características del Proyecto
* **Motor:** Desarrollado en Unity 6 utilizando C#.
* **Base de Datos en la Nube:** Conexión en tiempo real con **Firebase Firestore** para almacenar y acumular la puntuación y el progreso de los jugadores (`player_progress/jugador_1`).
* **Interfaz de Usuario Adaptativa:** Menú principal optimizado mediante *Canvas Scaler* para distintas resoluciones de pantalla.
* **Sistema de Notificaciones:** Avisos visuales en pantalla mediante banners de confirmación al momento de guardar el progreso en la base de datos.
* **Control de Rendimiento:** Limitación de fotogramas por código (`Application.targetFrameRate = 60`) para garantizar estabilidad en equipos con gráficos integrados.

---

## 🚀 Cómo Descargar y Jugar (Versión Ejecutable)

¿Quieres probar el juego sin necesidad de abrir el editor de Unity? ¡Es muy fácil!

1. Dirígete a la sección de **Releases** de este repositorio (o haz clic en el enlace de descarga directa en la descripción).
2. Descarga el archivo comprimido del ejecutable para Windows (`JohnsGame-Windows.zip`).
3. Descomprime el archivo en cualquier carpeta de tu computadora.
4. Haz doble clic en el archivo **`JohnsGame.exe`** para iniciar la aventura.
